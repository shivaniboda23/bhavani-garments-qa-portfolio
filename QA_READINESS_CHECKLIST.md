## Start applying immediately after publishing

Do not delay applications until you learn every QA tool. This portfolio is sufficient evidence for entry-level manual QA applications.

Recommended target titles:

- QA Trainee
- Manual Testing Trainee
- Junior Software Tester
- Software Test Engineer — Fresher
- Quality Analyst — Fresher
- Associate QA Engineer
- Application Testing Trainee

## Skills to strengthen while applying

Prioritize these in order:

1. SQL testing: `SELECT`, `WHERE`, `JOIN`, `GROUP BY`, aggregates, and data validation.
2. Browser DevTools: Network, Console, request payload, response, and status inspection.
3. API testing: variables, authorization, assertions, chaining, and negative cases.
4. Test design: boundary values, equivalence partitions, state transitions, and decision tables.
5. Basic automation only after the above: Playwright or Selenium for two stable smoke workflows.

Do not spend weeks learning TestRail, Zephyr, or advanced automation before applying. Those tools are learnable on the job and have lower immediate value than applications and interview practice.

## Weekly evidence rule

Only add genuine work to the portfolio. Record the date, environment, steps, expected result, actual result, status, and evidence. Never inflate experience or invent defects to increase counts.
